# php-basics-practice

## 概要

COACHTECH 教材 Tutorial 7-1「PHPの基礎 ハンズオン演習」で作成した成果物です。

商品価格計算プログラムを作成しました。

## 使用技術

- PHP 8.x
- Git / GitHub

## 学んだこと

- コメントの残し方
- 演算方法

## 動作確認

1. ターミナルで対象ディレクトリに移動します。
   ```bash
   cd ~/php-practice/src/7-1-6_hands-on/practice
   ```
2. 以下のコマンドを実行する。
   php price_calculator.php
3. ターミナルに計算結果が正しく出力されているか確認する。
